# Music Remote

Control the Music app on another Mac from your menu bar: a Mac mini on the stereo, played from your
MacBook. Now playing, transport, search, playlists, albums, an Up Next queue, AirPlay speakers and
Yamaha receivers, with media keys and Control Center.

Install the same app on both Macs. On the Mac that plays the music, turn on
**Settings → This Mac → Let other Macs control Music on this Mac**. Every other Mac with the app finds
it on the local network by itself.

## Install

- **Homebrew**: `brew install --cask goudsmit-tech/tap/music-remote`
- **Download**: the latest `MusicRemote-<version>.dmg` from [Releases](https://github.com/goudsmit-tech/MusicRemote/releases/latest);
  open it and drag the app to Applications.

Requires macOS 15 Sequoia or later.
